## 方法论

四层架构：
- **L0 物理约束层**：物理世界的基本规则。不可违反的现实边界。不需验证。
- **L1 定义层**：概念定义 → 形式化演绎。分析性真理。
- **L2 桥接层**：L1 连接到真实人类社会。多来源 IEA 加权验证。
- **L3 推论层**：L1 × L2 → 可检验的现实世界命题。

本体系**永远不完备**。每一轮迭代产出阶段性结论。
