📡 API 接口文档 只读

所有接口均为 GET，无需认证。修改操作由 Claude 代理执行，不对外暴露。

GET /api/health
健康检查。返回节点数、边数、最后更新时间。
curl https://human-society.intelab.cn/api/health
GET /api/nodes
节点列表，支持过滤：?layer=L3 &type=deduction &status=verified &q=搜索词
curl "https://human-society.intelab.cn/api/nodes?layer=L4&status=verified"
GET /api/nodes/{id}
单节点详情 + 上游依赖（depends_on）+ 下游被依赖（depended_by）。
curl https://human-society.intelab.cn/api/nodes/DED-001
GET /api/edges
边列表，支持过滤：?relation=depends_on &source=DED-001 &target=AXIOM-002
curl "https://human-society.intelab.cn/api/edges?source=DED-001"
GET /api/articles
文章引用列表。?node_id=DED-042 过滤某实体相关文章；省略返回全部。
curl "https://human-society.intelab.cn/api/articles?node_id=DED-042"
GET /api/search
全文搜索节点（ID/术语/人话摘要）。?q=搜索词 必填。
curl "https://human-society.intelab.cn/api/search?q=国家"
GET /api/stats
图谱统计信息：总节点数、各层/各类型分布、生成时间。
curl https://human-society.intelab.cn/api/stats
GET /graph-data.json
完整数据集（全部节点 + 全部边），适合批量处理。
curl https://human-society.intelab.cn/graph-data.json
